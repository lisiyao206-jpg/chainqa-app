# 账户、私钥与签名：你的身份是一把钥匙

## 区块链上没有「用户名+密码」

在普通网站上，你的身份由平台保管：注册账号、设置密码，忘了还能找客服重置。

区块链上没有这样的中心机构。你的身份完全由一串数字决定，这串数字叫**私钥**。谁掌握了私钥，谁就能控制对应账户里的资产。

以太坊上有两种账户：一种是由私钥控制的**外部账户**（普通用户用的就是它），另一种是由代码控制、没有私钥的**合约账户**（也就是后面要学的智能合约）。本章说的「账户」指外部账户。

可以这样理解：**区块链账户就像一个透明的保险箱，私钥就是唯一的钥匙。** 箱子里有多少钱，大家都能看到；但只有拿着钥匙的人能把钱取出来。

## 私钥、公钥、地址：一条单向的路

账户的三个核心要素，是一步步推导出来的：

```
私钥  ──(椭圆曲线运算)──>  公钥  ──(Keccak-256 哈希)──>  地址
 (绝对保密)                (可以公开)             (公开的收款号)
```

1. **私钥**：一个随机生成的超大数字，在以太坊中写出来是 64 个十六进制字符，是一切的源头，必须严格保密。
2. **公钥**：由私钥通过数学运算得到，可以公开给别人，用来验证你的签名。
3. **地址**：对公钥做 Keccak-256 哈希，取最后 20 个字节，再在前面加上 `0x`，就得到地址。它相当于你的「银行卡号」，别人向这个地址转账。以太坊地址共 42 个字符，例如 `0x5e97870f263700f46aa00d967821199b9bc5a120`。

最重要的一点：这条路是**单向的**。从私钥算出公钥和地址很容易，但从地址或公钥反推出私钥，在现有计算能力下几乎不可能。所以你可以放心公开地址，却绝不能泄露私钥。

## 数字签名：证明「这笔交易是我发的」

当你要转账时，钱包会用你的私钥对这笔交易生成一个**数字签名**，再把交易和签名一起发到网络上。

其他节点收到后，可以从签名中还原出你的公钥，并核对它是否对应发送地址。验证能同时证明两件事：

1. **身份可信**：这个签名只有持有对应私钥的人才能生成，说明交易确实是你发的。
2. **内容没被改过**：签名和交易内容绑定在一起，哪怕金额被改动一个数字，验证就会失败。

打个比方：签名就像一个**特制的火漆印章**，只有你能盖出这个印，而且信封一旦被拆开重封，印章就会破损。整个过程中，私钥从未离开你的设备，网络上传递的只有签名。

## 助记词：私钥的「人类可读版」

私钥是一长串没有规律的字符，很难抄写和记忆。于是人们设计了**助记词**。

助记词是按照 **BIP-39** 标准，从一个固定的英文单词表中选出的一组单词，最常见的是 **12 个或 24 个**，比如：

```
apple  river  ...  (共 12 或 24 个单词，顺序很重要)
```

钱包可以通过助记词**恢复出私钥**，进而恢复账户。换手机、重装钱包时，只要输入助记词，资产就能找回来。

这也意味着：**助记词等同于私钥**，拿到助记词就等于拿到了你的全部资产。

## 为什么绝对不能泄露

请牢牢记住下面几条：

1. **私钥和助记词不能发给任何人。** 包括自称「客服」「官方」「技术支持」的人，正规项目永远不会向你索要它们。
2. **不要截图、不要拍照上传网络、不要存在聊天记录或云笔记里。** 这些地方一旦被入侵或误分享，资产就会被瞬间转走。
3. **丢了就找不回。** 区块链上没有「忘记密码」按钮，也没有人能帮你冻结或追回。私钥和助记词都丢失，资产就永远锁在链上。
4. **推荐做法**：用纸笔抄写助记词，离线保存在安全的地方，必要时多处备份。

以太坊官方文档有一句话说得很透：你从未真正「持有」加密货币，你持有的是私钥，资金始终记在以太坊的账本上。钱包也只是帮你管理账户的应用，并不是账户本身。在区块链世界里，**你就是自己的银行**，自由和责任是一体的。

## 小结

1. 外部账户由私钥控制，私钥是你在链上唯一的身份凭证；合约账户没有私钥，由代码控制。
2. 私钥 → 公钥 → 地址是单向推导，地址可以公开，私钥无法被反推。
3. 数字签名用私钥生成、用公钥验证，既能证明交易是你发的，也能证明内容未被篡改。
4. 助记词可以恢复私钥，与私钥同等重要，泄露或丢失都无法挽回。
