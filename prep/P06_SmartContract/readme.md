# 智能合约：写在链上、自动执行的协议

## 从自动售货机说起

街边的**自动售货机**，就是一份最朴素的「智能合约」。

它的规则写死在机器里：投入 3 元，按下可乐按钮，就掉出一瓶可乐。整个过程不需要售货员，也不用讨价还价，只要条件满足，结果就自动发生。

1. **规则事先写好**：价格、商品、找零方式都已设定。
2. **条件满足即执行**：钱够了、按了按钮，机器立刻出货。
3. **无需信任对方**：你不需要认识机器的老板，只需要相信机器会按规则运行。

智能合约就是把这台「售货机」搬到了区块链上。

## 智能合约是什么

**智能合约**是部署在区块链上的一段程序。它是位于链上某个特定地址的代码（函数）和数据（状态）的集合：数据比如账户余额，函数比如「转账」「存款」。在以太坊上，合约本身也是一种账户，有地址、能持有余额，但不受任何人的私钥控制，而是按代码运行。当有人发起交易调用它的函数时，所有节点都会按照代码执行，并把结果记到链上。

「智能合约」这个概念早在上世纪 90 年代就由尼克·萨博（Nick Szabo）提出，自动售货机也正是他用过的比喻；区块链的出现，才让这个设想真正落地。

和传统合同相比：

| 对比项 | 传统合同 | 智能合约 |
| --- | --- | --- |
| 表现形式 | 纸面文字 | 计算机代码 |
| 执行方式 | 依靠人去履行，违约要找法院 | 条件满足自动执行 |
| 结果是否公开 | 通常不公开 | 链上公开可查 |

需要注意，「智能」并不是说它有人工智能，而是指它能**自动执行**。

## 用 Solidity 写一个计数器

以太坊和 FISCO BCOS 上的智能合约，最常用的编程语言是 **Solidity**（以太坊上还有 Vyper，FISCO BCOS 还支持基于 Rust 的 Liquid）。Solidity 吸收了 C++、JavaScript 的一些特性，学过这些语言会觉得眼熟。下面是一个极简的计数器合约：

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;  // 指定编译器版本

// 一个简单的计数器合约
contract Counter {
    uint256 public count;  // 计数值，保存在链上，任何人都能读取

    // 让计数加 1
    function increment() public {
        count += 1;
    }

    // 读取当前的计数值
    function getCount() public view returns (uint256) {
        return count;
    }
}
```

部署合约本身也是一笔交易，在以太坊上需要支付 Gas。部署之后，任何人调用 `increment()`，链上的 `count` 就会加 1；调用 `getCount()` 则可以查看当前值。看不懂也没关系，训练营会从零讲起。

## 部署之后的三个特点

智能合约一旦部署到链上，就具备以下特点：

1. **代码公开**：合约代码（至少是编译后的字节码）存放在链上，任何人都可以查看和分析。这意味着「好人」能审查它，「坏人」也能研究它。
2. **通常不能修改**：合约部署后，部署在该地址上的代码无法再改动。如果发现了 bug，不能像普通网站那样「打个补丁」，往往只能部署新合约并迁移数据；有些项目会事先采用「代理模式」等升级方案，但它需要提前设计，实施起来也需要时间。
3. **执行结果一致**：同样的输入，在所有节点上都得到同样的结果。没有任何人能单方面改变执行结果，包括合约的作者。

这三个特点，正是智能合约「可信」的来源，同时也是它「危险」的来源。

## 为什么上线前审计如此重要

把这些特点放在一起想一想：代码公开、无法随意修改、自动执行、而且合约里往往直接存放着真金白银。

一旦代码里藏着漏洞：

1. 攻击者可以公开研究代码，找到漏洞；
2. 合约会忠实地按照有漏洞的逻辑执行，把资产交给攻击者；
3. 开发者很难第一时间修复，损失往往无法挽回。

所以，智能合约行业有一条铁律：**上线之前必须做充分的测试和安全审计**。审计就是由独立的安全人员审查代码，找出可能被利用的漏洞。不过审计也不是万能药，它不能保证找出所有问题，开发者自己写出高质量、经过测试的代码才是根本。这正是本平台想帮你掌握的能力。

## 小结

1. 智能合约像链上的自动售货机：规则写在代码里，条件满足就自动执行。
2. 智能合约是部署在区块链上的程序，常用 Solidity 语言编写。
3. 合约部署后代码公开、通常不能修改、所有节点执行结果一致。
4. 正因为难以修复且直接管理资产，合约上线前的安全审计至关重要。
