# 区块链 + 供应链金融：让末端的小企业也能借到钱

## 这一章要做什么

上一章看了区块链在司法存证里的用法。这一章看它在金融里的一个典型场景：**供应链金融**。

我们先弄清楚中小企业「融资难」到底难在哪，再看国家政策对供应链金融和区块链的定位，最后用一个简化的合约，演示应收账款怎样在链上一级一级流转、又始终能追溯到源头。

## 先认识一条供应链

以一家汽车厂为例：

```
汽车厂（核心企业）
  └─ 一级供应商：座椅厂
        └─ 二级供应商：面料厂
              └─ 三级供应商：纺纱厂
```

汽车厂规模大、信用好；越往下的供应商规模越小。

现实中，核心企业买东西常常不是马上付钱，而是开出一张「几个月后付款」的凭证，这就是**应收账款**：对座椅厂来说，它「应该收到」汽车厂的一笔钱，只是还没到期。

## 融资难，难在哪

座椅厂急需用钱时，可以拿着汽车厂的应收账款去银行融资，银行认可汽车厂的信用，问题不大。

但面料厂、纺纱厂就难了：它们和汽车厂没有直接的合同，银行**看不到它们和核心企业之间的关系**，也很难确认它们手里的单据是真是假、有没有被重复拿去融资。核心企业的信用，传不到供应链的末端。

这就是常说的中小企业「融资难、融资贵」的原因之一。

## 国家政策怎么说

2020 年 9 月，中国人民银行会同工业和信息化部、司法部、商务部、国资委、市场监管总局、银保监会、外汇局，联合印发了《关于规范发展供应链金融 支持供应链产业链稳定循环和优化升级的意见》（银发〔2020〕226 号）：

| 要点 | 内容 |
| --- | --- |
| 发文单位 | 人民银行等八部门 |
| 结构 | 从把握内涵和方向、规范发展和创新、基础设施建设、政策支持、防范风险、监管约束六个方面，提出 23 条政策措施 |
| 和技术相关 | 提出合理运用区块链、大数据、人工智能等新一代信息技术，加强供应链金融服务平台、信息系统等的安全保障 |

> 原文见本章末尾的「参考资料」。

## 区块链能帮上什么忙

把应收账款记到一条由核心企业、供应商、银行共同参与的联盟链上，会带来三点变化：

| 原来的问题 | 上链之后 |
| --- | --- |
| 末端供应商和核心企业没有直接关系，银行看不到 | 每一笔拆分转让都记在链上，能一路**追溯到核心企业开出的那一笔**（信用穿透） |
| 单据真假难辨，可能被重复融资 | 链上一笔应收账款同一时间只有一个持有人，金额拆出去就少了，**不能一女二嫁** |
| 各方各记各的账，对账麻烦 | 多方共享同一本账，记录**不可随意篡改**，减少对账成本 |

注意，区块链解决的是**信息可信和可追溯**的问题，并不会凭空产生信用：最终能不能按时还钱，仍然取决于核心企业本身的经营状况。

## 动手：应收账款的拆分与追溯

本章附带了一个简化的合约 `Receivable.sol`，点「在合约练习场打开」就能载入。它有四个核心函数：

| 函数 | 谁能调用 | 作用 |
| --- | --- | --- |
| `issue(to, amount)` | 只有核心企业（部署合约的账户） | 开出一笔应收账款给一级供应商 |
| `split(id, to, amount)` | 这笔账款的持有人 | 拆出一部分，转给下一级供应商 |
| `pay(id)` | 只有核心企业 | 到期付款，标记为已付 |
| `levelOf(id)` | 任何人（只读） | 从这一笔往上追溯，返回它是第几级、源头是哪一笔 |

在练习场里，所有操作都由你自己的同一个账户发出，所以可以这样体验：

1. 部署合约，你就是「核心企业」；
2. 调用 `issue`，`to` 填你自己的地址（点一下 `core` 就能看到），金额填 `100`，开出第 1 笔；
3. 调用 `split`，把第 1 笔拆出 `30` 给自己（模拟转给二级供应商），得到第 2 笔；
4. 再把第 2 笔拆出 `10`，得到第 3 笔；
5. 调用 `levelOf(3)`：返回 `3, 1`，表示这一笔是第 3 级，源头是核心企业开出的第 1 笔；
6. 调用 `bills(1)`：金额变成了 `70`，拆出去的 30 已经不在第 1 笔里，不能重复使用；
7. 试试 `split(1, …, 1000)`：交易被拒绝（`bad amount`），拆分金额不能超过剩余金额。

> 真实系统里，核心企业、各级供应商、银行是不同的账户，权限更复杂，还要处理到期日、贴现、法律确权等问题。这个合约只保留了「拆分 + 追溯」这一个核心思路。

## 小结

- 供应链金融的难点，是核心企业的信用传不到末端的小供应商；
- 2020 年人民银行等八部门的意见，对规范发展供应链金融作出了系统部署，并提出合理运用区块链等技术；
- 区块链让应收账款的每一次拆分转让都**可追溯、不可重复使用**，实现「信用穿透」；
- 区块链解决的是信息可信，不能替代核心企业本身的偿付能力。
