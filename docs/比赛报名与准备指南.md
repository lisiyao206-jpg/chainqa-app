## 2. 竞赛材料清单

按照比赛要求，通常需要提交以下材料：

### A. 代码仓库（GitHub / Gitee）

**要求**：
- 仓库公开，或至少设置为可 review
- 代码结构清晰，注释完整
- 完整 README（项目介绍、技术架构、启动方式）
- 完整 Git 提交历史
- 环境配置说明

**需要准备的事项**：

1. **推到远程仓库**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: 链知答 LIANZHIDA"
   git remote add origin <your-repo-url>
   git push -u origin main
   ```

2. **更新 README.md**
   - 增加项目名称、团队信息、参赛方向
   - 增加「比赛材料」部分：架构图、评测报告、演示视频链接

3. **整理 `docs/` 目录**
   - 已创建的：`README.md`、`系统架构说明.md`、`技术文档.md`、`评测报告.md`、`比赛报名与准备指南.md`、`MCP使用说明.md`

### B. 技术文档（PDF，建议 < 30 页）

**文档结构**：
1. 项目概述（1 页）
2. 系统架构图（1 页）
3. AI 技术方案（3-4 页）
   - 智谱 AI 模型选型
   - RAG 问答流程
   - AI 审计 Agent
   - 规则扫描器
   - 变种题自动出题
4. 创新点（2 页）
   - RAG + 拒答机制
   - 审计 Agent 工具调用
   - 规则扫描 + AI 组合
   - 变种题闭环
   - 3D 交互体验
5. 数据证明（3-5 页）
   - RAG 效果评测报告
   - 逐题结果表
6. 部署方式（1 页）
7. 未来展望（1 页）

**如何导出 PDF**：

方案一：GitHub 仓库 + GitHub Actions 自动生成 PDF
```yaml
# .github/workflows/pdf.yml
name: Build PDF
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm i -g markdown-pdf
      - run: markdown-pdf docs/技术文档.md -o docs/技术文档.pdf
```

方案二：本地导出
```bash
# 使用 pandoc
pandoc docs/技术文档.md -o docs/技术文档.pdf --pdf-engine=weasyprint

# 或者使用 VS Code 插件「Markdown PDF」
```

### C. 演示视频（MP4，5-8 分钟，1080p 起步）

**视频结构（建议分镜）**：

| 时间 | 内容 | 展示动作 |
|---|---|---|
| 0:00-0:15 | 项目介绍 | 展示大厅 3D 场景，旁白：项目名称、团队、比赛方向 |
| 0:15-0:45 | 核心功能：RAG 问答 | 录屏演示白帽导师问答，展示引用标注 |
| 0:45-1:30 | RAG 检索过程 | 展示向量检索、相似度、拒答机制 |
| 1:30-2:30 | AI 审计 | 输入合约代码，展示审计 Agent 输出 |
| 2:30-3:30 | 变种挑战 | AI 出题、规则验题、变种题库 |

**录制建议**：
- 分辨率：1920x1080（1080p 起步）
- 格式：MP4
- 画质：H.264 编码，声音清晰
- 背景：纯色背景或桌面，避免杂乱
- 字幕：可选，增强专业感

| 10 | 结尾 | 感谢 + 联系方式 |

### 答辩常见问题

**Q：为什么选择 RAG 问答方向？**
A：RAG 能够让 AI 基于可靠的教材资料回答问题，避免幻觉，提高准确率。我们的评测数据证明 RAG 显著优于直接问大模型。

**Q：如何确保 AI 回答不错误？**
A：三重防护：① 提示词限定只依据资料；② 相似度阈值过滤不相关资料；③ 回答带引用编号，用户可核对原文。

**Q：AI 审计 Agent 是怎么工作的？**
A：审计 Agent 具备工具调用能力，会先扫描合约发现漏洞，再查 SWC 漏洞库了解原理和修复方法，最后检索教材确认知识点，最后输出带出处的审计报告。

**Q：变种题系统如何保证质量？**
A：AI 出题后，规则扫描器自动验题，确保题一定可解。即使 AI 写错，也能通过规则发现，保证题库质量。
