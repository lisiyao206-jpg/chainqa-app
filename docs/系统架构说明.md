# 系统架构说明

> 一页纸看懂链知答：做什么、怎么做、为什么这样设计。完整内容见 [技术文档.md](技术文档.md)。

---

## 一句话

**链知答**是一个区块链安全 AI 教育平台：学生读带出处的教材、问不乱答的 AI 导师，再到**真实的 FISCO BCOS 联盟链**上写合约、接受攻击检验；老师建班布置任务，系统按知识点自动生成学情。

---

## 总体架构

```
浏览器（Vue 3 + TS）
   │  HTTP + SSE（nginx，80 端口）
   ▼
Node.js 后端（server.mjs）
   ├─ 学习：教材 · 知识点 · 防御战 · 思维导图 · 学习报告 · 班级
   ├─ AI  ：RAG 问答 · 审计 Agent · 规则扫描 · 截图识别 · AI 安全
   ├─ 链上：现场编译（solc 0.6.10 / 0.8.38）· 合约练习场 · 链上实验场
   └─ 社区：学术论坛（匿名、话题）· 聊天 · 反馈与教材纠错
   │                 │                         │（仅本机）
   ▼                 ▼                         ▼
SQLite（28 表）    智谱 AI                 WeBASE-Front → FISCO BCOS 4 节点
```

全部部署在一台腾讯云轻量服务器上，网站、WeBASE、联盟链各由 systemd 守护。

---

## 三条核心流程

**① 白帽导师（RAG）**
提问 → 向量化 → 检索教材前 4 段 → 相似度 < 0.45 拒答 → 否则只依据资料回答并标注出处 → 流式输出

**② 链上实验场**
提交代码 → 编译 → 每项检验重新部署 → 业务检验 + 3 种攻击 → 实时推送交易与区块号 → 给出「挡住几种、还差什么、去哪里找问题」

**③ 学习闭环**
教材（防御战）+ 漏洞猎人（星级）+ 链上实验（通过）+ 错题 → 按 16 个知识点计算掌握度 → 学生报告 / 班级学情 / AI 学习建议

## 为什么这样设计

| 决定 | 原因 |
|---|---|
| 自己搭联盟链，而不是用模拟器 | 「改不了」「被攻击」要在真链上才可信；也能发现模拟器发现不了的问题（如 FISCO 时间戳是毫秒） |
| 选 FISCO BCOS | 国产开源联盟链，国内文档完整、网络可达；课程实验环境也是它 |
| 自建合约练习场 | Remix 在国内经常打不开；自建后还能一键载入教材代码 |
| RAG + 阈值拒答 | 教育场景里答错比不答更有害，宁可拒答也不编造 |
| 后端不用 Web 框架、数据库用 SQLite | 依赖少、部署简单，一台 2 核 4G 服务器即可承载 |
| 教材标出处 + 纠错入口 | 作者能力有限，用官方出处和用户反馈共同保障内容准确 |
