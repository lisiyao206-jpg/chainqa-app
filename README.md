# 链知答 LIANZHIDA

> 以 AI 为核心的区块链安全教育平台：AI 白帽导师只依据教材回答、句句标出处；AI 审计 Agent 自主调用工具检查合约；AI 按知识点分析学情、给出学习建议。学生还能在**真实的国产联盟链 FISCO BCOS** 上亲手写合约、抵御攻击。

**在线访问**：<http://43.136.20.150>（腾讯云服务器，注册即可使用，注册时可选择学生或老师身份）

## 亮点

| 亮点 | 说明 |
|---|---|
| **AI 白帽导师：不乱答** | 基于 RAG：只依据教材回答、每句标出处、相似度不够就拒答。对照评测：准确度 97 vs 85，超纲题拒答率 100% vs 30%（见 `eval/`） |
| **AI 审计 Agent** | 大模型通过函数调用自主规划步骤：规则扫描、查 SWC 漏洞库、检索教材，过程实时可视化，输出带出处的审计报告；同一套工具以 MCP 协议开放给外部 AI 编程助手 |
| **AI 贯穿学习全程** | 选中教材文字一键提问、AI 生成章节思维导图、读完一章 AI 出题做防御战、AI 根据知识点掌握度写学习建议；AI 安全模块拦截提示词注入、私钥与助记词泄露 |
| **真实上链，不是模拟** | 作者在腾讯云上用官方 `build_chain.sh` 搭建了 4 节点 FISCO BCOS v2.11.0 联盟链，通过 WeBASE-Front 接入。链上实验场和合约练习场里的每次部署、每笔交易都有真实的区块号和交易哈希 |
| **链上实验场：在链上建安全墙** | 学生修改有漏洞的合约 → 部署上链 → 系统派攻击者发起多种真实攻击交易，同时检验正常业务不受影响；没挡住时写清「挡住了几种、还差哪一项、去哪里找问题」 |
| **合约练习场：替代国内打不开的 Remix** | 浏览器里写合约、编译、部署、调用函数。支持 Solidity 0.8（编译到 byzantium 指令集以兼容 FISCO BCOS v2），可 import OpenZeppelin 5.0.2；教材 73 个带合约的章节中 64 个可一键载入运行 |
| **教材可核对** | 五条学习路线、84 章；自编章节的结论都附官方出处（最高人民法院、中国政府网、FISCO BCOS 官方文档等），每章末尾有纠错入口，后台可集中处理 |
| **教与学闭环** | 老师建班、布置章节和关卡任务、分享资料、发起视频会议；系统按 16 个知识点自动生成每个学生的学习报告和全班学情 |

## 要解决的问题

| 问题 | 现状 | 链知答的做法 |
|---|---|---|
| 区块链安全人才缺口大，入门难 | 教材分散，原理抽象；不少高校区块链专业缺少能讲清原理和安全的师资 | 五条学习路线从零基础到合约安全，配 AI 导师随时答疑 |
| 通用大模型答题会编造 | 学生分辨不了 AI 回答的对错，容易被误导 | RAG 只依据教材回答、标注出处、超出范围就拒答 |
| 学了没地方练 | 主流在线工具 Remix 在国内经常打不开；本地搭链门槛高 | 平台自带合约练习场，直连作者搭建的 FISCO BCOS 联盟链 |
| 安全只停留在概念 | 读过「重入攻击」，但没亲手防过 | 链上实验场在真链上发起攻击，检验学生写的防护是否有效 |
| 老师难以掌握学情 | 线下作业无法按知识点统计 | 系统按 16 个知识点自动生成学生报告和班级学情，AI 给出学习建议 |

## 快速开始（本地运行）

### 1. 环境要求

1. **Node.js 22.5 及以上**（用到内置 `node:sqlite`）
2. 智谱 AI 的 API Key：<https://open.bigmodel.cn>
3. （可选）FISCO BCOS + WeBASE-Front：不配置也能运行，只是链上实验场和合约练习场不可用

### 2. 安装依赖

```bash
npm install            # 后端：solc 编译器、OpenZeppelin（见 package.json）
cd web && npm install  # 前端
```

### 3. 准备教材

```bash
git clone https://github.com/AmazingAng/WTF-Solidity.git knowledge/WTF-Solidity
```

自编教材（`prep/`、`fisco/`、`frontier/`）已在仓库中。`knowledge/` 不上传仓库（开源语料，体积大）。

### 4. 配置环境

复制 `.env.example` 为 `.env`，按注释填写（`.env` 已加入 `.gitignore`）：

| 变量 | 说明 |
|---|---|
| `ZHIPU_API_KEY` | 必填，智谱 AI 的 API Key |
| `ADMIN_ACCOUNT` | 必填，先注册一个账号，把 6 位账号填在这里，重启后即为管理员 |
| `WEBASE_URL` | 可选，WeBASE-Front 地址，如 `http://127.0.0.1:5002/WeBASE-Front`；不填则关闭链上功能 |
| `PORT`、`SMS_MODE` | 可选，见 `.env.example` |

### 5. 构建知识库（只需一次）

```bash
node rag.mjs build
```

把教材切片并向量化，生成 `vectors.json`；只处理新增或变更的片段。

### 6. 启动

```bash
# 开发：两个终端
node server.mjs              # 后端，默认 3000 端口
cd web && npm run dev        # 前端，http://localhost:5173

# 生产：前端打包后由后端直接提供
cd web && npm run build && cd .. && node server.mjs
```

### 7. 搭建联盟链（可选）

服务器上的部署步骤（搭链、WeBASE、systemd、nginx）见 [`docs/技术文档.md`](docs/技术文档.md) 的「部署」一节；搭链过程也写成了教材第 02 路线的章节。

## 安全

1. API Key 只在后端 `.env`，不进前端、不进仓库；数据库、上传文件也不进仓库
2. 密码 scrypt 加盐哈希；所有 SQL 参数化；每次数据操作都校验 `user_id`；管理员权限在后端校验
3. 读取教材和合约文件时检查路径，防止路径穿越；上传文件扩展名白名单
4. 链上操作：同一用户同时只能有一个写操作，部署和交易每分钟限 20 次；只读查询单独限流
5. AI 安全：提示词注入检测、内容审核、私钥 / 助记词防泄露
6. 节点以 127.0.0.1 组网，WeBASE 与节点端口不在防火墙开放；外网只能访问 80 端口的网站
