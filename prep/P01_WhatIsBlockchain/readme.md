# 区块链是什么：一本人人都有的账本

## 从「记账」说起

想象一个班级要管理班费。最常见的做法是：选一位**班长**，所有收支都由他记在一个本子上。谁交了钱、买了什么，全看这本账。

这种方式叫**中心化记账**：只有一个人（或一个机构）掌握账本，其他人只能相信他。

我们生活中的银行、支付平台，本质上也是这样。你的存款余额，其实就是银行服务器里的一条记录。你相信这个数字，是因为你相信银行。

中心化记账简单高效，但它有几个隐患：

1. 如果记账人**记错了**，别人很难发现。
2. 如果记账人**故意改账**，别人没有证据反驳。
3. 如果账本**丢了或被烧了**，所有记录一起消失。

## 换个思路：大家一起记账

现在换一种玩法：班上每个同学手里都有一本**一模一样的账本**。

每当发生一笔收支，就当众宣布：「小明交了 20 元班费。」所有人核对无误后，各自在自己的本子上记下这一笔。

这样一来：

1. 想偷偷改账？你得同时改掉大多数同学手里的本子，几乎不可能。
2. 某个人的本子丢了？找其他同学抄一份就行。
3. 不需要特别信任某一个人，因为**账是大家一起核对的**。

这就是区块链最核心的思想：**不靠某一个权威，而是靠大家共同记录、共同验证，来建立信任。**

## 分布式账本：区块链的本质

用更专业一点的话说，区块链是一种**分布式账本**。

1. **账本**：它记录的是「谁在什么时候做了什么」，比如一笔转账。
2. **分布式**：这本账不存在某一台电脑里，而是由网络中的许多台电脑（称为**节点**）各自保存一份完整副本。这些节点往往属于不同的个人或机构：公链上可能有成千上万个节点，联盟链上则通常是各成员机构的节点。
3. **按顺序追加**：新的记录只能往后添加，就像日记一页页往后写，已经写下的内容很难被改动。

```
     节点A        节点B        节点C        节点D
   [账本副本]   [账本副本]   [账本副本]   [账本副本]
        \           |            |           /
         \__________|____________|__________/
                  网络中实时同步、互相核对
```

至于「为什么很难被改动」、「大家怎么达成一致」，我们会在后面几章慢慢揭开。

## 去中心化的好处

不依赖单一中心，被称为**去中心化**。它带来几个明显的好处：

1. **难以篡改**：历史记录一旦被大家确认，想要修改需要付出极高的代价。
2. **公开透明**：在很多区块链上，任何人都可以查看全部交易记录。
3. **不怕单点故障**：少数节点宕机或离线，整个系统照常运行。
4. **降低信任门槛**：互不认识的人，也能在同一本账上放心地做交易。

## 去中心化的代价

天下没有免费的午餐。「大家一起记账」也有明显的代价：

1. **效率较低**：一笔交易要让很多节点都确认，速度通常比银行内部系统慢。
2. **成本更高**：每个节点都要存储同一份数据、做同样的计算，整体上消耗更多的存储、算力和网络资源。而且和普通网站「加机器就能变快」不同，给区块链增加节点，主要提升的是容错能力和公信力，并不会让它处理得更快。
3. **难以修改**：难篡改是优点，但如果真的记错了，纠正起来也同样困难。
4. **需要规则**：成千上万个节点要步调一致，必须有一套严谨的规则，也就是后面要讲的**共识机制**。

所以，区块链并不是什么都比传统系统强，它适合的是**多方参与、彼此缺乏信任、又需要一份可靠公共记录**的场景。

## 小结

1. 中心化记账依赖单一记账人，简单高效，但存在记错、篡改、丢失的风险。
2. 区块链是一种**分布式账本**：许多节点各自保存同一份账本，共同记录、共同验证。
3. 去中心化带来难篡改、透明、抗故障等好处，代价是效率较低、成本更高。
4. 区块链最适合多方协作、彼此不完全信任、需要可信记录的场景。
