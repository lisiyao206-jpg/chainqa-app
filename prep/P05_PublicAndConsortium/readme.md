# 公链与联盟链：以太坊和 FISCO BCOS

## 三种区块链：公链、联盟链、私链

区块链并不只有一种。按照「谁能加入、谁来记账」，通常分为三类。可以用三种「社区」来类比：

1. **公链**像一座**开放的公共广场**：任何人都可以进来，任何人都可以参与记账，所有记录对所有人公开。比特币、以太坊都是公链。
2. **联盟链**像一个**行业协会**：只有经过审核的成员机构才能加入，记账由这些成员共同负责。
3. **私链**像**一家公司的内部系统**：由单个机构控制，主要在内部使用。

## 一张表看懂区别

| 对比项 | 公链 | 联盟链 | 私链 |
| --- | --- | --- | --- |
| 谁能加入 | 任何人 | 经过准入的成员机构 | 单个机构内部 |
| 谁来记账 | 全网节点竞争或质押参与 | 联盟成员的指定节点 | 机构自己 |
| 去中心化程度 | 最高 | 中等（多中心） | 最低 |
| 性能 | 通常较低 | 通常较高 | 通常最高 |
| 隐私 | 数据普遍公开 | 可按权限控制访问 | 完全内部可控 |

总的来说，**公链更开放，联盟链更可控**。节点越少、身份越明确，达成共识越快，性能也越好，但去中心化程度会相应降低。这又是一次「好处和代价」的取舍。

## 以太坊：支持智能合约的典型公链

比特币主要用来记录转账，功能相对单一。**以太坊**则更进一步：它不仅能记账，还能运行程序。

这些运行在以太坊上的程序就是**智能合约**，开发者常用 **Solidity** 语言来编写。有了智能合约，人们可以在链上发行代币、搭建去中心化交易所、做借贷、做数字藏品等各种应用。

以太坊因此被称为「世界计算机」，也是目前智能合约生态最丰富的公链之一。我们后面学习的 Solidity 和各类合约漏洞，很多都源自以太坊生态中的真实经验。

## FISCO BCOS：国产开源联盟链平台

**FISCO BCOS** 是**金融区块链合作联盟（深圳）**（简称**金链盟**）开源工作组于 2017 年推出的国产安全可控区块链底层开源平台。金链盟由微众银行、深圳市金融科技协会等国内机构共同发起，FISCO BCOS 的代码和核心技术全面开源，可免费使用。

它有几个值得关注的特点：

1. **兼容 Solidity**：可以直接用 Solidity 编写和部署智能合约（支持到 0.8.11 版本），以太坊上学到的开发知识大部分都能迁移过来；此外还支持用 Rust 编写合约（WBC-Liquid）。
2. **联盟链设计**：节点需要准入，内置权限治理框架（开启后对链的修改需多方投票授权），并采用 PBFT（及其改进版 rPBFT）、Raft 等适合联盟场景的共识算法。其中 PBFT 是「立即一致」的，交易可以做到秒级确认。
3. **支持国密算法**：国密版 FISCO BCOS 把签名验签、节点通信、数据落盘加密等底层模块的算法全部换成国密算法，例如用 SM2 签名替代 ECDSA、用 SM3 哈希替代 SHA-256/SHA-3、用 SM4 加密替代 AES，并配有国密 Solidity 编译器。
4. **应用广泛**：已在金融、政务、公益等领域落地超过 600 个应用，例如区块链服务网络 BSN、中国银联区块链可信存证服务等。

## 为什么我们选择 FISCO BCOS

本平台的合约部署和学习记录存证，选用了 FISCO BCOS，主要基于以下考虑：

1. **兼容 Solidity，学用一致**：你在训练营中学习的 Solidity 代码，可以直接部署到链上运行和验证，学到的就是能用的。
2. **国产自主可控**：开源、由国内金融机构和科技企业主导研发，全面支持国密算法，并适配国产服务器、操作系统、数据库，符合国内应用的发展方向和合规需求。
3. **适合教学**：联盟链确认快，而且「不发币、不挖矿」，部署合约和调用函数不需要购买真实的加密货币作为手续费，降低了学习门槛和成本。
4. **适合存证**：记录一旦上链就难以篡改，非常适合记录学习成果、任务完成情况等需要长期可信保存的数据。

## 小结

1. 区块链分为公链、联盟链和私链，区别在于谁能加入、谁来记账、性能与隐私。
2. 以太坊是支持智能合约的典型公链，合约多用 Solidity 编写。
3. FISCO BCOS 是金链盟开源工作组于 2017 年推出的国产开源联盟链平台，兼容 Solidity，支持 PBFT、Raft 等共识和国密算法，已广泛用于金融、政务、公益等领域。
4. 本平台选择 FISCO BCOS，是因为它兼容 Solidity、自主可控，并且适合教学和存证。
