# Solidity极简入门

## Solidity 简介
- 编写EVM智能合约的编程语言
- 掌握Solidity是参与链上项目的必备技能
- 基于对象，高级语言

## 开发工具：Remix
- 以太坊官方推荐的IDE
- 浏览器中快速开发和部署合约
- 左侧菜单：文件、编译、部署

## 第一个 Solidity 程序
- 三行代码示例
- 注释：说明许可
- 版本声明：限定编译器版本
- 合约声明：创建合约，声明变量

## 编译并部署代码
- Ctrl + S 编译代码
- 部署按钮进入部署页面
- Remix虚拟机模拟以太坊链
- 部署合约，查看结果
