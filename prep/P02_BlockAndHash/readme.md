# 区块与哈希：为什么改不了

## 哈希：数据的「指纹」

每个人都有独一无二的指纹。数据世界里也有类似的东西，叫**哈希值**。

**哈希函数**是一种特殊的计算方法：不管你输入一个字、一篇文章还是一部电影，它都会输出一串**固定长度**的字符。区块链中常用的有 SHA-256、Keccak-256（以太坊使用）等，国密版 FISCO BCOS 则使用我国的 SM3 算法。

比如用 SHA-256 计算单词 `hello`，结果是：

```
hello  →  2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
```

这串字符，就是 `hello` 的「指纹」。

## 哈希的三个关键特性

哈希之所以能撑起区块链的安全，靠的是下面三个特性：

1. **同样的输入，永远得到同样的输出。** 今天算、明天算，在你的电脑上算、在别人的电脑上算，`hello` 的哈希永远相同。所以大家可以各自计算、互相核对。
2. **改一个字，结果完全不同。** 只把 `hello` 改成 `hellp`，哈希就面目全非：

   ```
   hello  →  2cf24dba5fb0a30e...938b9824
   hellp  →  fdd7585e08c4e2af...08aa4ce7
   ```

3. **无法反推。** 拿到一串哈希值，没有办法倒推出原始数据是什么，就像看到指纹无法还原出一个人的长相。

一句话：哈希能让我们**快速发现数据有没有被动过**。生活中其实也常用到它：很多软件下载页会附上文件的哈希值，下载完自己算一遍，对得上就说明文件没有被篡改或损坏。

## 区块里装了什么

区块链上的交易不是一条一条零散存放的，而是分批打包成一个个**区块**，像账本里的一页纸。这样做是为了让全网节点有时间对同一批交易达成一致，比如以太坊大约每 12 秒才产生一个新区块。一个区块大致分为两部分：

| 部分 | 主要内容 | 通俗理解 |
| --- | --- | --- |
| **区块头** | 前一个区块的哈希、时间戳、区块编号、交易根哈希、状态根哈希等 | 这一页的「页眉」 |
| **区块体** | 本区块包含的一笔笔交易 | 这一页的「正文」 |

其中**交易根哈希**（常说的默克尔根）可以理解为：把本区块所有交易的哈希两两组合、层层计算，最后得到的一个总哈希。只要任何一笔交易被改动，这个根哈希就会变。以太坊使用的是默克尔树的改进版「默克尔帕特里夏树」，原理相同。

## 用哈希把区块连成链

关键在于区块头里的那一项：**前一个区块的哈希**。

每个新区块都记着上一个区块的「指纹」，于是区块就像一节节车厢，被哈希这根「挂钩」首尾相连，形成一条**链**：

```
+-------------+     +-------------+     +-------------+
|  区块 1     |     |  区块 2     |     |  区块 3     |
| 前哈希: 0   |<----| 前哈希: H1  |<----| 前哈希: H2  |
| 交易...     |     | 交易...     |     | 交易...     |
| 本块哈希 H1 |     | 本块哈希 H2 |     | 本块哈希 H3 |
+-------------+     +-------------+     +-------------+
```

这就是「区块链」名字的由来：**区块 + 链**。

## 为什么改一个区块，后面全对不上

假设有人想偷偷修改区块 1 里的一笔交易：

1. 交易一改，区块 1 的默克尔根变了，区块 1 的哈希也从 H1 变成了 H1'。
2. 可是区块 2 里记录的「前哈希」仍然是 H1，和 H1' 对不上，链条在这里**断开**了。
3. 想接上，就得重新计算区块 2；区块 2 一变，区块 3 又对不上……一直要改到最新的区块。
4. 更难的是，网络里还有大量节点保存着原始账本。就算你把自己电脑上的那份从头到尾全改一遍，也只能「骗自己」：一旦和其他节点一起共识、同步，不一致的数据就会被发现并拒绝。

所以，篡改历史记录不是「改一个数字」那么简单，而是要**重做后面所有区块，还要说服大多数节点**，代价极高。这就是区块链「难以篡改」的秘密。

## 小结

1. 哈希是数据的「指纹」：同样输入同样输出、改一点面目全非、无法反推。
2. 区块由区块头和区块体组成，区块头记录前一个区块的哈希、时间戳和交易根哈希（默克尔根）等信息。
3. 每个区块都记着前一个区块的哈希，因此区块被首尾相连成一条链。
4. 修改任意一个历史区块，会让它之后的所有区块都对不上，篡改代价极高。
